## 文件 1：`test_llm.py`  
**作用**：不依赖 LangChain，直接用 OpenAI 兼容接口调用 DeepSeek，理解最底层的大模型调用方式。

```python
import os
from dotenv import load_dotenv
from openai import OpenAI

# 加载 .env 文件，把 DEEPSEEK_API_KEY 读进环境变量
load_dotenv()

# 创建客户端，指定 API Key 和 DeepSeek 的服务器地址
client = OpenAI(
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# 发送对话请求，messages 里放用户的问题
response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "user", "content": "介绍你自己"}
    ]
)

# 提取并打印回答
print(response.choices[0].message.content)
```

## 文件 2：`test_langchain.py`  
**作用**：使用 LangChain 的管道语法（prompt | llm | parser），体验链式调用，并理解 `from_messages` 设定 system 人设。

```python
import os
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 加载 API Key
load_dotenv()

# 创建大模型对象
llm = ChatOpenAI(
    model="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# 创建提示词模板：用 from_messages 可以设定 system 人设
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个专业的翻译助手，只输出英文翻译，不要解释。"),
    ("user", "把下面的中文翻译成英文：{chinese}")
])

# 输出解析器：把模型返回的对象转成纯字符串
parser = StrOutputParser()

# 用管道符 | 把三部分串成一条链
chain = prompt | llm | parser

# 执行链，传入模板变量
result = chain.invoke({"chinese": "今天天气真好"})
print(result)
```

## 文件 3：`rag_demo.py`  
**作用**：完整 RAG 流程——加载文档 → 切分 → 向量化 → 存入 Chroma → 检索 → 拼接提示词 → 大模型生成答案。这是项目最核心的代码。

```python
import os
from dotenv import load_dotenv
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_chroma import Chroma
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

# 加载环境变量（DeepSeek API Key）
load_dotenv()

# 1. 加载本地文档 knowledge.txt
loader = TextLoader("knowledge.txt", encoding="utf-8")
docs = loader.load()

# 2. 把长文档切成小块，每块约100字，相邻块重叠20字
text_splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=20)
splits = text_splitter.split_documents(docs)
print(f"文档被分成了 {len(splits)} 块")

# 3. 使用本地下载好的 HuggingFace 模型做嵌入（把文本变成向量）
embeddings = HuggingFaceEmbeddings(
    model_name="D:/Tools/CodeOnPython/models/all-MiniLM-L6-v2"
)
print("嵌入模型加载成功！")

# 4. 把切分后的文档存入 Chroma 向量数据库
vectorstore = Chroma.from_documents(documents=splits, embedding=embeddings)
print("向量存储创建成功！")

# 5. 创建检索器：每次找最相似的 2 块
retriever = vectorstore.as_retriever(search_kwargs={"k": 2})

# 6. 创建大模型（DeepSeek）
llm = ChatOpenAI(
    model="deepseek-chat",
    api_key=os.getenv("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com"
)

# 7. 提示词：system 里明确要求“根据资料回答，不知道就说不知道”
prompt = ChatPromptTemplate.from_messages([
    ("system", "你是一个专业的认知健康助手。请严格根据以下资料回答问题，如果资料中没有相关信息，请直接说“根据现有资料无法回答”。\n\n资料：\n{context}"),
    ("user", "{question}")
])

# 辅助函数：把检索到的文档块拼成一个长字符串
def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)

# 8. 构建 RAG 链：检索 → 拼接 → 提示词 → 大模型 → 提取文本
rag_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

# 9. 测试提问
print("--- 开始提问 ---")
question = "什么是RAG？"
answer = rag_chain.invoke(question)
print(f"问题：{question}")
print(f"回答：{answer}")

print("\n--- 再问一个 ---")
question2 = "轻度认知障碍是什么？"
answer2 = rag_chain.invoke(question2)
print(f"问题：{question2}")
print(f"回答：{answer2}")
```

## 📌 三份代码的关系
- **test_llm.py**：最底层，直接调 API，理解“请求-响应”模式。
- **test_langchain.py**：引入 LangChain，用管道把提示词、模型、输出解析器串起来。
- **rag_demo.py**：在 LangChain 基础上加入文档检索，实现 RAG。

## ✅ 复习要点
1. `.env` 文件不要提交到 GitHub。
2. `from_messages` 是 RAG 必用的提示词构造方式。
3. RAG 链的核心是 `{"context": retriever | format_docs, "question": RunnablePassthrough()}`。
4. 嵌入模型可以本地加载，避免网络问题。
